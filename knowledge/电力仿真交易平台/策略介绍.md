## 直接报价
- 根据当前数据直接报价。
	特点是规则简单，主要根据当前数据直接报价。

| 策略名称                                 | 参与者  | 作用            |
| ------------------------------------ | ---- | ------------- |
| `powerplant_energy_naive`            | 发电机  | 按边际成本报价       |
| `demand_energy_naive`                | 负荷   | 以高愿付价格购买给定负荷  |
| `exchange_energy_naive`              | 跨区交换 | 进口低价供给，出口高价需求 |
| `powerplant_energy_naive_profile`    | 发电机  | 提交24小时整体报价    |
| `powerplant_energy_naive_otc`        | 发电机  | 参与双边交易市场      |
| `demand_energy_naive_otc`            | 负荷   | 参与双边交易市场      |
| `powerplant_energy_naive_redispatch` | 发电机  | 参与再调度市场       |
- `demand_energy_naive`：我要购买2082.7 MWh，只要市场价格不超过3000 EUR/MWh，我都愿意购买。这相当于刚性负荷。它不会因为价格从40涨到50，就减少用电量。
- `exchange_energy_naive`：跨区交换单元的基础策略，外部电能向本地出售，属于供给，正数 0 EUR/MWh；外部区域购买本地电能，属于需求负数，按照最高的支付意愿。

## 启发式策略
启发式策略会考虑更多运行信息和预测，但仍然是人为设计的规则。

|策略名称|作用|
|---|---|
|`demand_energy_heuristic_elastic`|构造价格弹性需求曲线|
|`powerplant_energy_heuristic_flexable`|综合启停成本、爬坡约束和价格预测报价|
|`powerplant_energy_heuristic_block`|提交跨多个小时的块报价|
|`powerplant_energy_heuristic_linked`|提交相互关联的报价|
|`storage_energy_heuristic_flexable`|根据预测电价决定充电或放电|
|`powerplant_capacity_heuristic_balancing_pos`|参与正备用市场|
|`powerplant_capacity_heuristic_balancing_neg`|参与负备用市场|
## 优化策略
这类策略先建立数学优化问题，再根据优化结果报价。

|策略名称|作用|
|---|---|
|`household_energy_optimization`|优化居民侧用电计划|
|`industry_energy_optimization`|优化工业侧用电计划|
|`powerplant_energy_optimization_dmas`|优化发电机报价|
|`storage_energy_optimization_dmas`|优化储能充放电和报价|
## 强化学习策略
这类策略不固定写死报价规则，而是让智能体根据市场收益学习报价。

|策略名称|智能体决定什么|
|---|---|
|`powerplant_energy_learning`|发电机两部分功率的报价价格|
|`powerplant_energy_learning_single_bid`|发电机单条报价价格|
|`storage_energy_learning`|储能报价价格及充放电方向|
|`renewable_energy_learning_single_bid`|新能源机组报价|
|`portfolio_learning`|运营商整个机组组合的报价|
