## 3. 优化策略
这类策略先建立数学优化问题，再根据优化结果报价。

| 策略名称                                  | 作用         |
| ------------------------------------- | ---------- |
| `household_energy_optimization`       | 优化居民侧用电计划  |
| `industry_energy_optimization`        | 优化工业侧用电计划  |
| `powerplant_energy_optimization_dmas` | 优化发电机报价    |
| `storage_energy_optimization_dmas`    | 优化储能充放电和报价 |
## 4. 强化学习策略
这类策略不固定写死报价规则，而是让智能体根据市场收益学习报价。

| 策略名称                                    | 智能体决定什么       |
| --------------------------------------- | ------------- |
| `powerplant_energy_learning`            | 发电机两部分功率的报价价格 |
| `powerplant_energy_learning_single_bid` | 发电机单条报价价格     |
| `storage_energy_learning`               | 储能报价价格及充放电方向  |
| `renewable_energy_learning_single_bid`  | 新能源机组报价       |
| `portfolio_learning`                    | 运营商整个机组组合的报价  |
