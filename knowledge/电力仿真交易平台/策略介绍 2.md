## 3. 优化策略
这类策略先建立数学优化问题，再根据优化结果报价。

| 策略名称                                  | 作用         |
| ------------------------------------- | ---------- |
| `household_energy_optimization`       | 优化居民侧用电计划  |
| `industry_energy_optimization`        | 优化工业侧用电计划  |
| `powerplant_energy_optimization_dmas` | 优化发电机报价    |
| `storage_energy_optimization_dmas`    | 优化储能充放电和报价 |
之前的 `powerplant_energy_heuristic_flexable`，核心思路大致是：
> 根据边际成本、最小出力、最大出力、启动成本等信息，用人为设计好的规则决定“报多少 MW、报多少钱”。

## 3.1 powerplant_energy_optimization_dmas
不是直接套规则，而是先问：
> 假设已经知道未来一段时间的预测电价，机组应该如何运行，才能使总利润最大？

机组参数 + 未来价格预测→利润最大化优化​→最优发电计划→报价

所以优化器不只是决定：
> “发多少电？”

它还要决定：
> “什么时候开机？”  
> “什么时候停机？”  
> “开机以后至少运行多久？”  
> “爬坡能不能跟得上？”

利润​=售电收入−燃料成本−碳排放成本−启动成本

核心问题：什么时候开机、什么时候关机、开机后发多少电。

机组参数 + 未来价格预测→利润最大化优化→最优发电计划→报价
### 3.1.1 一句话概括
先用预测电价求解单台机组的跨时段利润最大化模型，再把不同电价情景下的最优出力差异转换为带链接关系的块报价。

优化模型要决定什么？

|        变量        |  类型   |     含义      |
| :--------------: | :---: | :---------: |
|      $P_t$       | 连续变量  |  机组实际出力，MW  |
| $\widetilde P_t$ | 连续变量  | 超过最低出力的灵活部分 |
|      $z_t$       | 0-1变量 |    是否开机     |
|      $v_t$       | 0-1变量 |  是否在该小时启动   |
|      $w_t$       | 0-1变量 |  是否在该小时停机   |

|        符号        |       含义       |
| :--------------: | :------------: |
|    $P^{prev}$    | 优化开始前，机组的实际出力  |
|      $P_0$       | 优化范围内第一个小时的出力  |
|     $R^{up}$     |  每小时最多增加多少 MW  |
|    $R^{down}$    |  每小时最多减少多少 MW  |
|    $P^{min}$     |    开机后的最低出力    |
| $\widetilde P_t$ |   超过最低出力的部分    |
|      $z_t$       | 开机状态，开机为1，关机为0 |
$$P_t = z_t P^{min} + \widetilde{P}_t$$
### 第一个小时的约束：
$$P_0 \le P^{prev} + R^{up}$$
表示第一个小时不能增加得太快。
$$P_0 \ge P^{prev} - R^{down}$$
表示第一个小时也不能下降得太快。
### 后续时间
$$\begin{aligned} \widetilde{P}_{t} - \widetilde{P}_{t-1} &\le R^{up} z_{t-1} \\ \widetilde{P}_{t-1} - \widetilde{P}_{t} &\le R^{down} z_{t} \end{aligned}$$

| 上一小时 | 当前小时 |   模型结果    |
| :--: | :--: | :-------: |
|  关机  |  关机  |   出力保持0   |
|  关机  |  开机  |  从最低出力启动  |
|  开机  |  开机  | 按爬坡速率改变出力 |
|  开机  |  关机  | 必须先降到最低出力 |
### 最小开机、停机时间
* 最小开机时间为 $U$；
* 最小停机时间为 $D$。
模型通过最近几个小时的启动、停机记录限制状态：
$$z_t \ge \sum_{k=t-U}^{t-1} v_k$$
意思是：最近刚启动过，就不能马上关机。
$$1 - z_t \ge \sum_{k=t-D}^{t-1} w_k$$
意思是：最近刚停机过，就不能马上重新启动。
## 3.2 pay_as_clear_complex_dmas(站在市场的角度)

|模块|做决定的人|决定什么|
|---|---|---|
|`powerplant_energy_optimization_dmas`|单台机组|如何报价|
|`pay_as_clear_complex_dmas`|市场运营商|接受哪些报价|
各机组生成报价→市场收集报价→市场优化出清→确定成交量和统一价格

它收集所有机组和负荷的订单，在满足需求以及母块、子块约束的前提下，选择总报价成本最低的一组电量，并计算统一出清价格。

|类型|含义|接受方式|
|---|---|---|
|`single_bid`|普通购电/需求订单|当前实现全部接受|
|`single_ask`|普通售电订单|可以部分接受|
|`linked_ask`|母块或子块售电订单|遵守父子关系|
|`exclusive_ask`|互斥方案|同一主体最多选择一个方案|
## 3.3 storage_energy_optimization_dmas
查看未来一整天的预测电价，决定每个小时充电、放电还是不动作，并保证储能电量始终可行。

| 源码变量         | 我们更容易理解的名称  | 含义             |
| ------------ | ----------- | -------------- |
| `p_plus[t]`  | $P_t^{ch}$  | 第 t 小时的充电功率    |
| `p_minus[t]` | $P_t^{dis}$ | 第 t 小时的放电功率    |
| `volume[t]`  | $E_t$       | 第 t 小时结束后的储能电量 |
$$\Delta E_t = \eta_{ch} P_t^{ch} - \frac{P_t^{dis}}{\eta_{dis}}$$
|对比|火电DMAS|储能DMAS|
|---|---|---|
|主要决策|开停机和发电量|充电量、放电量、SOC|
|时间耦合|启动、最小运行、爬坡|SOC连续变化|
|多场景方式|电价整体加减|改变电价曲线形状|
|订单结构|母块＋链接子块|多套互斥方案|
|市场约束|子块依赖父块|最多选择一个完整方案|
## 3.4 household_energy_optimization
居民先根据预测电价安排热泵、电池、电动车等设备的运行时间，得到每个时段必须从电力市场购买的电量，再提交购电订单。

它不能随意移动全部居民负荷。照明、电视等 `inflex_demand` 不能移动，只有电池、热储能、电动车等具有物理灵活性的设备可以调整。

预测电价→居民内部优化→形成固定购电计划

## 3.5 industry_energy_optimization
工厂必须完成规定的产品产量，但可以在设备、库存和生产流程允许的范围内，把部分生产安排到电价较低的时段。

工业负荷优化不是直接移动一条负荷曲线，而是：
> 生产目标 + 设备约束 + 物料平衡 + 能源价格 $\rightarrow$ 最优生产计划

然后：
> 最优生产计划 $\rightarrow$ 每小时总用电量 $\rightarrow$ 负值购电订单
