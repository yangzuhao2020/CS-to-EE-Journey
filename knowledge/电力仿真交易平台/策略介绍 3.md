## 4. 强化学习策略
这类策略不固定写死报价规则，而是让智能体根据市场收益学习报价。

| 策略名称                                    | 智能体决定什么       |
| --------------------------------------- | ------------- |
| `powerplant_energy_learning`            | 发电机两部分功率的报价价格 |
| `powerplant_energy_learning_single_bid` | 发电机单条报价价格     |
| `storage_energy_learning`               | 储能报价价格及充放电方向  |
| `renewable_energy_learning_single_bid`  | 新能源机组报价       |
| `portfolio_learning`                    | 运营商整个机组组合的报价  |
## 和其他策略的不同
| 策略    | 决策依据     | 如何得到报价       |
| ----- | -------- | ------------ |
| 启发式策略 | 人工经验     | 成本加固定利润      |
| 优化策略  | 成本、约束和预测 | 求解数学优化模型     |
| 强化学习  | 历史交易经验   | 神经网络逐渐学习报价规律 |
强化学习没有“正确报价答案”。它只能不断尝试：
> 这样报价 → 市场是否接受 → 最后赚了多少钱。

然后慢慢调整自己的报价方法。
其中：
- $s_t$：当前观察到的信息；
- $a_t$：智能体采取的报价动作；
- $r_t$：市场出清后得到的奖励；
- $s_{t+1}$：下一个时段的新状态。
$s_t \rightarrow a_t \rightarrow \text{市场出清} \rightarrow r_t \rightarrow s_{t+1}$

|    信息    | 数量  |     作用     |
| :------: | :-: | :--------: |
| 未来残余负荷预测 | 12  | 判断未来电力是否紧张 |
| 未来市场价格预测 | 12  |  判断未来价格高低  |
| 最近实际成交电价 | 12  |  了解市场近期表现  |
| 上一时刻机组出力 |  1  | 判断机组当前是否运行 |
|  当前边际成本  |  1  |  知道发电成本底线  |
未来负荷很高、预测电价上涨、最近成交价也在上涨、机组已经运行、边际成本为30元/MWh。
## 4.1 powerplant_energy_learning
`powerplant_energy_learning` 输出两个连续动作：
$$a_t = [a_1, a_2]$$
动作一般在 $[-1, 1]$ 范围内，然后乘以最高报价：
$$p_i = a_i P_{max}^{bid}$$
程序把两个价格排序：
- 较低价格：用于最低稳定出力 $P_{\min}$；
- 较高价格：用于灵活出力 $P_{\max} - P_{\min}$。
其中，$P_{\max}$ 应明确为机组额定功率。
假设机组：
$$P_{\min} = 40\text{ MW}, \qquad P_{\max} = 100\text{ MW}$$
### 4.1.1 市场的反馈
假设市场出清价为：
$$p^{clear} = 50\text{ 元/MWh}$$
那么：
- 30元的40 MW报价被接受；
- 60元的60 MW报价没有被接受；
- 机组实际成交40 MW；
- 在统一出清市场中，成交部分按照50元结算。
### 4.1.2 奖励的计算
利润 $\Pi_t$ 的计算：
$$\Pi_t = p_t^{clear} E_t^{acc} - C_t^{variable} - C_t^{startup}$$
其中：$E_t^{acc} = P_t^{acc} \Delta t$：$E^{acc}$ 是成交电量 (MWh)，$P^{acc}$ 是成交功率 (MW)。

遗憾惩罚 $G_t$ 的计算：
$$G_t = \lambda \max\left(0,\ (P_t^{avail} - P_t^{acc})(p_t^{clear} - c_t^{marginal})\Delta t\right)$$
$\lambda$ 是可配置的遗憾惩罚系数。

奖励 $r_t$ 的计算：
$$r_t = \frac{\Pi_t - G_t}{B* P_{max}\Delta t}$$
$B$ 它是一个固定的缩放参数，单位是元/MWh，不能直接理解为市场最高限价，$\Delta t$以小时计。
$$a_t = \text{clip}(\pi(s_t) + \epsilon_t,-1,1)$$
其中：
- $\pi(s_t)$：Actor 给出的**归一化动作**；
- $\epsilon_t$：程序生成的随机探索噪声。
注意：适用于**常规训练阶段**。初始探索单独处理；评估时不加 $\epsilon_t$。
### 4.1.3 反馈情况
需要分成两部分看：
- 成交价格、成交量和发电利润，是市场出清产生的仿真反馈；
- “机会成本×惩罚系数”是人为设计的奖励塑形，并不是市场实际扣掉的钱。
## 4.2 模拟器是如何确定其他机组的报价
模拟器能够“生成”其他机组的报价，不等于它能够“准确预测”现实中其他公司的报价。

|机组|配置的策略|报价如何产生|
|---|---|---|
|Unit 1|`powerplant_energy_naive`|按边际成本报价|
|Unit 2|启发式策略|边际成本加固定利润|
|Unit 3|优化策略|求解内部优化模型|
|Unit 4|强化学习策略|Actor输出报价并加入噪声|

|角色|可以控制什么|
|---|---|
|研究者|每台模拟机组使用什么策略、成本和参数|
|RL机组|只能决定自己的报价|
|其他模拟机组|根据各自配置的策略独立报价|
|市场运营者|收集全部订单并执行出清|
|现实中的其他公司|无法被研究者真正控制|
缺陷：
	RL与模拟市场发生了真实交互，但模拟市场本身是否接近现实，取决于其他参与者行为模型是否合理。
