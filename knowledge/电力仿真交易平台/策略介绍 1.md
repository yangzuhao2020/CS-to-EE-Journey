# 1. 直接报价
- 根据当前数据直接报价。
	特点是规则简单，主要根据当前数据直接报价。

| 策略名称                                 | 参与者  | 作用            |
| ------------------------------------ | ---- | ------------- |
| `powerplant_energy_naive`            | 发电机  | 按边际成本报价       |
| `demand_energy_naive`                | 负荷   | 以高愿付价格购买给定负荷  |
| `exchange_energy_naive`              | 跨区交换 | 进口低价供给，出口高价需求 |
| `powerplant_energy_naive_profile`    | 发电机  | 提交24小时整体报价    |
| `powerplant_energy_naive_otc`        | 发电机  | 参与双边交易市场      |
| `demand_energy_naive_otc`            | 负荷   | 参与双边交易市场      |
| `powerplant_energy_naive_redispatch` | 发电机  | 参与再调度市场       |
- `demand_energy_naive`：我要购买2082.7 MWh，只要市场价格不超过3000 EUR/MWh，我都愿意购买。这相当于刚性负荷。它不会因为价格从40涨到50，就减少用电量。
- `exchange_energy_naive`：跨区交换单元的基础策略，外部电能向本地出售，属于供给，正数 0 EUR/MWh；外部区域购买本地电能，属于需求负数，按照最高的支付意愿。

# 2. 启发式策略
启发式策略会考虑更多运行信息和预测，但仍然是人为设计的规则。

|策略名称|作用|
|---|---|
|`demand_energy_heuristic_elastic`|构造价格弹性需求曲线|
|`powerplant_energy_heuristic_flexable`|综合启停成本、爬坡约束和价格预测报价|
|`powerplant_energy_heuristic_block`|提交跨多个小时的块报价|
|`powerplant_energy_heuristic_linked`|提交相互关联的报价|
|`storage_energy_heuristic_flexable`|根据预测电价决定充电或放电|
|`powerplant_capacity_heuristic_balancing_pos`|参与正备用市场|
|`powerplant_capacity_heuristic_balancing_neg`|参与负备用市场|
## 2.1 powerplant_energy_heuristic_flexable
考虑最低出力、启停状态、启动成本、爬坡、未来价格和热电联产。
	将一台机组拆成两条报价。第一部分属于最低稳定出力，然后第二部分属于灵活出力。
### 2.1.1 灵活出力定价
灵活出力一般按照边际成本报价，在已经保证最低出力的基础上，再增加发电需要消耗更多煤和排放配额，因此按照45.05 EUR/MWh报价。

### 2.1.2 稳定出力怎么定价
最低出力的价格取决于机组当前是“运行”还是“停机”。
- 停机：如果要让机组启动，除了燃料成本，还要支付启动成本。$$p_{\text{inflex}} = C_{\text{marginal}} + \frac{C_{\text{start}}}{T_{\text{expected}} \times P_{\text{min}}}$$
	所以，边际成本 + 启动费用=最低出力报价。
- 运行：如果现在关闭机组，将来再启动，还会产生启动成本。所以机组可能愿意让最低出力暂时少赚一点，甚至亏一点，也不愿意关闭。$$p_{\text{inflex}} = C_{\text{marginal}} - \text{避免重启带来的价值} - \text{供热收益}$$
### 2.1.3 未来价格预测
这个策略默认会观察未来约12小时的预测价格。如果未来总体上还能赚钱，但当前小时预测价格低于边际成本，策略可能把当前最低出力报价降低，甚至设为0。

|  时段   | 预测价格 | 边际成本 | 预期收益 |
| :---: | :--: | :--: | :--: |
|  当前   |  40  |  45  |  −5  |
| 下一小时  |  55  |  45  | +10  |
| 再下一小时 |  60  |  45  | +15  |
因此策略可能选择：当前保持最低出力运行。
### 2.1.4 额外的约束
在生成两条报价之前，代码还会检查：
- 机组可用率；
- 最大功率和最小功率；
- 当前已发功率；
- 已经在其他市场承诺的容量；
- 爬坡速度；
- 最小开机时间；
- 最小停机时间；
- 当前连续运行或停机时长；
- 热电联产的供热任务。
例如机组当前出力为300 MW，最大向上爬坡速度为每小时200 MW，那么下一小时最多只能达到：
$$300+200=500 MW$$
只有加入真实的启动成本、爬坡速度和最小启停时间后，启发式策略与朴素策略才会明显不同。

为什么不是最优？
	它没有联合求解未来24小时的全局利润最大化问题，也不能保证得到理论最优报价。
朴素策略只看“现在发一度电需要多少钱”；启发式策略还会考虑“现在停机后面是否要重新启动，以及未来几个小时是否值得继续运行”。

## 2.2 demand_energy_heuristic_elastic
把一个负荷拆成多档需求报价。电价低时多用电，电价高时少用电。它适合电动汽车充电、储能充电、可推迟工业任务，以及我们之前提到的“算电协同”——核心服务器负荷必须运行，而部分AI训练任务可以等电价降低后再执行。

|负荷等级|数量|最高愿付价格|
|---|--:|--:|
|核心负荷|5 MW|100 EUR/MWh|
|普通负荷|5 MW|75 EUR/MWh|
|可调负荷|5 MW|50 EUR/MWh|
|可推迟负荷|5 MW|25 EUR/MWh|
**最重要的部分：价格很高也要买**
**较重要的部分：价格合适才买**
**可推迟的部分：只有价格很低才买**

{
    "name": "demand_elastic",
    "technology": "elastic_demand",
    "bidding_EOM": "demand_energy_heuristic_elastic",
    "max_power": 20, # 最大可消费功率
    "min_power": 0, 
    "unit_operator": "elastic_de", 
    "elasticity": -0.05, # 需求价格弹性
    "elasticity_model": "isoelastic",  # 使用等弹性需求曲线
    "max_price": 3000, # 最高愿付价格
    "num_bids": 10 # 把需求曲线拆成10档报价
}

其中的弹性 `−0.05` 是什么意思呢？
$$ E = \frac{\text{需求量变化百分比}}{\text{价格变化百分比}} \quad E = -0.05$$
大致表示：
> 电价上涨1%，需求量下降0.05%。负号表示价格上涨时，用电量下降。

### 2.2.1 等弹性需求曲线
ASSUME 使用：
$$ Q(P) = Q_{\max} P^{E} $$
因为市场最高报价是3000，所以首先计算：
$$
Q_{\text{first}} = Q_{\max} P_{\max}^{E}
$$
代入：
$$
Q_{\text{first}} = 20 \times 3000^{-0.05} \approx 13.402\ \text{MW}
$$
这表示：
> 即使电价达到3000 EUR/MWh，这个负荷仍然希望购买约13.402 MW。

因此第一档报价为：
```
{
    "volume": -13.402,
    "price": 3000
}
```
剩余可调负荷为：20−13.402=6.598 MW
`num_bids=10`，除第一档外还需要生成9档，因此每档数量为：
$$
\frac{6.598}{9} \approx 0.733\ \text{MW}
$$

| 档位  |    本档数量    |   累计需求    | 最高愿付价格  |
| :-: | :--------: | :-------: | :-----: |
|  1  | −13.402 MW | 13.402 MW | 3000.00 |
|  2  | −0.733 MW  | 14.135 MW | 1034.05 |
|  3  | −0.733 MW  | 14.868 MW | 376.15  |
|  4  | −0.733 MW  | 15.601 MW | 143.65  |
|  5  | −0.733 MW  | 16.335 MW |  57.34  |
|  6  | −0.733 MW  | 17.068 MW |  23.83  |
|  7  | −0.733 MW  | 17.801 MW |  10.28  |
|  8  | −0.733 MW  | 18.534 MW |  4.58   |
|  9  | −0.733 MW  | 19.267 MW |  2.11   |
| 10  | −0.733 MW  | 20.000 MW |  1.00   |
已知需求 如何求解价格呢？
使用公式：
$$
P = \left( \frac{Q}{Q_{\max}} \right)^{1/E}
$$
已知：
- 最大需求 $Q_{\max} = 20$$ MW
- 弹性系数 E = -0.05 
- 第二档累计需求 Q = 14.1352296 MW

### 2.2.2 需求报价成立的条件
最高愿付价格≥市场出清价格；
### elasticity_model=linear
| 档位  |  数量   | 最高愿付价格 |
| :-: | :---: | :----: |
|  1  | −5 MW |  100   |
|  2  | −5 MW |   75   |
|  3  | −5 MW |   50   |
|  4  | −5 MW |   25   |
线性模型下降得比较均匀；等弹性模型则是弯曲的，通常保留一部分非常高价值的核心需求。

## 2.3 storage_energy_heuristic_flexable
也就是储能参与电能量市场的启发式报价策略。

原因是它正好把已经学过的内容连接起来：
- 充电时，储能是需求方，报价量为负数；
- 放电时，储能是供给方，报价量为正数；
- 根据预测电价决定充电还是放电；
- 受到 SOC、容量、充放电功率和效率限制。

### 2.3.1 基本规则：
```
当前预测电价 < 未来平均电价
→ 现在便宜
→ 充电买电

当前预测电价 > 未来平均电价
→ 现在较贵
→ 放电卖电
```

|           参数           |    数值    |   含义   |
| :--------------------: | :------: | :----: |
|   `max_power_charge`   | 1000 MW  | 最大充电功率 |
| `max_power_discharge`  |  992 MW  | 最大放电功率 |
|  `efficiency_charge`   |   0.86   |  充电效率  |
| `efficiency_discharge` |   0.90   |  放电效率  |
|       `min_soc`        |    0     | 最低荷电状态 |
|       `max_soc`        |    1     | 最高荷电状态 |
|       `capacity`       | 6076 MWh | 最大储能容量 |
### 2.3.2 SOC 是什么，如何更新？
SOC 是 State of Charge，中文叫荷电状态，表示储能当前有多满。

| SOC  |   含义    |
| :--: | :-----: |
|  0   |  完全没电   |
| 0.25 | 剩余25%容量 |
| 0.5  | 剩余50%容量 |
|  1   |  完全充满   |
ASSUME 中：
- 充电功率是负数；
- 放电功率是正数。

假设充电功率为 P_t < 0，则：$SOC_{t+1} = SOC_t + (-P_t * Δt * η_c) / C$
其中：
- $P_t$：市场实际成交功率，充电时为负；
- $Δt$：时间长度；
- $η_c$：充电效率；
- $C$：储能容量。

假设放电功率为 \( $P_t$ > 0 \)，则：
$$
SOC_{t+1} = SOC_t - \frac{P_t \Delta t}{\eta_d C}
$$
### 2.3.3 储能什么时候充电、什么时候放电
- 策略根据预测价格决定提交哪一种报价。
- 市场出清后，才决定是否真的充电或放电。

在 `storage_energy_heuristic_flexible` 中，默认计算当前时刻前后约 12 小时价格预测的平均值：$$\bar{p} = \operatorname{mean}(p_{t-12h},\ \ldots,\ p_t,\ \ldots,\ p_{t+12h})$$
$$p_t^{forecast} \quad \text{和} \quad \bar{p}$$
- 当前预测价格较高，SOC 允许放电，策略提交：
	- 正功率报价；
	- 作为供给方卖电；
	- 最大功率受到放电功率、SOC 和爬坡约束。

	放电报价：$$p_{\text{discharge}} = \frac{\bar{p}}{\eta_d}$$
- 当前预测价格较低，SOC 允许充电，策略提交：
	- 负功率报价；
	- 作为需求方购买电能充电；
	- 最大功率受到充电功率、SOC 和爬坡约束。

	充电报价：$$p_{\text{charge}} = \bar{p}\,\eta_c$$

|      市场价格 | 经济动作  |
| --------: | ----- |
|    不高于 43 | 适合充电  |
|  43～55.56 | 通常不动作 |
| 不低于 55.56 | 适合放电  |
预测价格选择报价方向→SOC确定可报数量→市场出清→成交后才真正更新SOC。
- `SOC = 0`：没有能量，不能放电；
- `SOC = 1`：已经充满，不能继续充电；
- `0 < SOC < 1`：可能充电或放电，但数量还受功率和爬坡限制。

|阶段|使用的量|作用|
|---|---|---|
|制定报价|可充/放功率、预测价格、当前 SOC|决定最多报多少|
|市场出清|`accepted_volume`|确定实际充电或放电量|
|状态更新|实际成交量|更新真实 SOC|
### 2.3.4 完整流程
- SOC 表示剩余电量比例；
- 预测电价决定想充电还是放电；
- 报价价格考虑充放电效率；
- 实际成交量决定 SOC 更新。

预测价格→生成储能报价→进入市场排序→确定出清价格→得到成交量→计算收益→更新SOC
