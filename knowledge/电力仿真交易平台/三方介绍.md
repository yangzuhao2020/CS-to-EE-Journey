## assume 基于代理的电力市场模拟工具箱
场景配置 → 创建发电机和负荷 → 生成报价 → 市场出清 → 下发调度结果 → 计算成本和收益 → 写入数据库

官方将它定义为一个包含可变可再生能源的小型案例，也就是在基本市场仿真中加入风电、光伏一类出力随时间变化的机组。它主要展示市场机制，不等于完整的电网潮流仿真。

demand_units.csv：定义1个买电方；
powerplant_units.csv：定义4个卖电方。

powerplant_energy_naive 逻辑
	计算边际发电成本
		↓
	计算当前最多还能发多少电
		↓
	以边际成本作为报价
		↓
	提交卖电订单

边际成本：发电机在当前基础上，再多生产1 MWh电能所增加的成本。
### 卖方成本
|成本|含义|
|---|---|
|固定成本|不发电也可能存在|
|边际成本|多发1 MWh增加的成本|
|平均成本|总成本除以总发电量|
## 燃料价格和碳价
**边际成本公式：**
$$
MC = \frac{\text{燃料价格}}{\text{效率}} + \frac{\text{碳价} \times \text{排放因子}}{\text{效率}} + \text{附加成本}
$$

![[Pasted image 20260908205012.png]]
- 绿色：`Demand volume`，买方成交量
- 蓝色：`Supply volume`，卖方成交量
两条线几乎完全重合，所以绿色被蓝色盖住了。这说明每个小时都有：
$$成交需求量=成交供应量$$
黄色阶梯线：市场出清价格，按照报价排序完成出清之后得到的结果，而不是出清之前就确定的价格。

**多真实电力现货市场的核心机制就是这样**：
1. 发电机组申报“愿意发多少电、最低接受什么价格”。
2. 市场运营机构统一收集报价。
3. 在满足需求和电网安全的前提下，原则上优先安排低报价机组。
4. 最后一台满足需求的边际机组决定该时段的市场价格。
5. 成交机组按照市场规则结算，许多市场采用统一边际价格。

## exchange 虚拟参与者
当前电力市场中添加一个“外部电网/跨区交易”的虚拟参与者，使当前市场能够进口和出口电能。
{
	name, # 这个虚拟交换单元的名称
	bidding_EOM, # 在电能量市场 EOM 中采用固定进口、出口报价策略
	price_import, # 进口电能以 0 EUR/MWh 申报
	price_export, # 出口需求的最高愿付价格为 2999 EUR/MWh
	unit_operator # 运营商
}

| 物理过程        | 在 ASSUME 里的角色 | 报价量符号 |
| ----------- | ------------- | ----: |
| 外部电网 → 当前市场 | 进口，是供给        |    正数 |
| 当前市场 → 外部电网 | 出口，是需求        |    负数 |

市场会先按照报价从低到高购买电能。进口电能报价为 `0 EUR/MWh`，所以它会排在报价为 `13.63、25.65、45.05 EUR/MWh` 的本地机组前面。

如果市场需求是 `2810 MWh`，出清顺序就是：
1. 先接受进口电能 `400 MWh`
2. 再接受 Unit 1 的 `1000 MWh`
3. 再接受 Unit 2 的 `1000 MWh`
4. 最后从 Unit 3 接受 `410 MWh`

**注意：**
- `0` 是进口方愿意接受的最低卖价；
- 它的作用是让进口电能排在供给队列前面；
- 最终结算价仍然由最后一台成交机组决定；
- “优先”不等于绝对保证成交，只是相对于报价更高的机组更早被选择。

### 进口和出口可以同时存在
德国可能同时：
- 从法国进口电能；
- 向奥地利出口电能。

ASSUME 在这个例子里没有分别建立每一个相邻区域，而是把它们合并成一个虚拟的 `exchange` 单元。

| 数据                | 市场中的角色          | 报价量 |         报价价格 |
| ----------------- | --------------- | --: | -----------: |
| `exchange_import` | 外部电能向本地出售，属于供给  |  正数 |    0 EUR/MWh |
| `exchange_export` | 外部区域购买本地电能，属于需求 |  负数 | 2999 EUR/MWh |
