## 大写字母带点 $\dot{I}$ 或 $\dot{U}$ 含义
表明它是复数，**只保留每个波形的“大小”（有效值）和“相对位置”（相位差）**，把它们变成带点的复数（$\dot{U}, \dot{I}$）。小写字母不带点： $i$ 或 $u$ 表明为瞬时值。
## 相量的表现形式
同一个相量通常有三种等价的表示方法（以电流有效值相量为例，$\dot{I} = \frac{I_m}{\sqrt{2}}$）：
1. **指数形式**：$\dot{I} = I e^{j\phi}$
2. **极坐标形式**：$\dot{I} = I \angle \phi$ （工程中最常用，直观看到大小和角度）
3. **代数形式**：$\dot{I} = a + jb$ （适合做加减法）
## 解相量法
- **相量法思想**：激励（电源）是正弦波，响应（电流/电压）也是**同频**的正弦波。
- **KVL / KCL 变换**：在正弦稳态下，它们改写成了**代数方程**（加减法）。
- **基本步骤**：
    1. 设未知量（时域表示）；
    2. 转为相量；
    3. 列相量方程并解出结果；
    4. 还原回时域（完成）。
例如：根据基尔霍夫电压定律（KVL），回路中电压满足：
$$5\cos(2t + 30^\circ) = u_1 + u_2 + u_3$$
展开成三角函数就是：
$$5\cos(2t + 30^\circ) = U_1\cos(2t+\phi_1) + U_2\cos(2t+\phi_2) + U_3\cos(2t+\phi_3)$$
$$5\angle 30^\circ = R \cdot I\angle\phi + j\omega L \cdot I\angle\phi + \frac{1}{j\omega C} I\angle\phi$$
## 电阻的复数形式
- **设定电流**：假设流过电阻的电流是正弦波 $i = I_m \cos(\omega t + \phi)$。
    - 把它转化为**有效值相量**就是：$\dot{I} = \frac{I_m}{\sqrt{2}} \angle \phi$
- **计算电压**：根据欧姆定律，电阻两端的电压 $u = R \cdot i = R \cdot I_m \cos(\omega t + \phi)$。
    - 把这个电压也转化为**有效值相量**就是：$\dot{U} = \frac{R \cdot I_m}{\sqrt{2}} \angle \phi$
在复平面（横轴为实部，纵轴为虚部）上：
- **电流相量 $\dot{I}$**：角度为 $\phi$。
- **电压相量 $\dot{U}$**：角度也是 $\phi$，但长度比 $\dot{I}$ 长了 $R$ 倍（假设 $R > 1$）。
这两个相量**完全重合/共线**，指向同一个方向。在工程上，我们称之为**电压与电流同相（In phase）**。这意味着它们在时域中会同时达到最大值，同时穿过零点。
## 电感的复数形式
- **定义电流：** 首先假设流过电感 $L$ 的正弦交流电流为：
    $i = \sqrt{2} I \cos(\omega t + \varphi)$
- **计算电压：** 根据电感元件的特性（电压等于电感量乘以电流的变化率），利用公式 $u = L \frac{di}{dt}$ 进行求导运算：
    $u = L \sqrt{2} I \cdot (-\sin(\omega t + \varphi) \cdot \omega)$
- **相位调整：** 利用三角函数公式，将 $-\sin$ 转化为 $\cos$，得出电感电压的最终时域表达式：
    $u = \omega L \sqrt{2} I \cos(\omega t + \varphi + 90^\circ)$
**相量形式：**
- **电流相量：** 提取电流的有效值和初相，表示为：
    $\dot{I} = I \angle \varphi$
- **电压相量：** 同理，提取电压的有效值和初相：
    $\dot{U} = \omega L I \angle (\varphi + 90^\circ)$
- **引入复数：** 在复平面中，相位加上 $90^\circ$ 相当于乘以虚数单位 $j$，因此公式可以改写为：
    $\dot{U} = \omega L I \cdot \angle \varphi \cdot j = j\omega L \cdot I \angle \varphi$
- **最终结论：** 将电流相量代入，得到电感元件在频域下的欧姆定律表达式：
    $\dot{U} = j\omega L \cdot \dot{I}$
电感会使得电压超前电流 90 度。
## 电容的复数形式
- **定义电压：** 这一次首先假设电容 $C$ 两端的正弦交流电压为：
    $u = \sqrt{2} U \cos(\omega t + \varphi)$
- **计算电流：** 根据电容元件的特性（电流等于电容量乘以电压的变化率），利用公式 $i = C \frac{du}{dt}$ 对电压进行求导：
    $i = C \cdot \sqrt{2} U \cdot (-\sin(\omega t + \varphi) \cdot \omega)$
- **相位调整：** 同样利用三角函数公式，将 $-\sin$ 转化为 $\cos$，得出电容电流的最终时域表达式：
    $i = \omega C \sqrt{2} U \cos(\omega t + \varphi + 90^\circ)$
    _(这一步证明了在电容元件中，电流的相位超前电压 **90°**，或者说电压滞后电流 **90°**)_
**向量分析：**
- **电压相量：** 提取电压的有效值和初相，表示为：
    $\dot{U} = U \angle \varphi$
- **电流相量：** 提取上面求出的电流的有效值和相位：
    $\dot{I} = \omega C U \angle (\varphi + 90^\circ)$
- **引入复数：** 在复平面中，相位加上 $90^\circ$ 相当于乘以虚数单位 $j$，因此电流相量可以改写为：
    $\dot{I} = j\omega C \cdot U \angle \varphi = j\omega C \cdot \dot{U}$
**电容的阻抗：**
- 由上面的推导已知：$\dot{I} = j\omega C \cdot \dot{U}$
- 将其变形求电压 $\dot{U}$，得到：
    $\dot{U} = \frac{\dot{I}}{j\omega C}$ （或者写成 $\dot{U} = \frac{1}{j\omega C} \cdot \dot{I}$）
- 右侧还给出了去掉相位后，纯有效值（幅值）之间的关系：
    $U = \frac{1}{\omega C} I$

## 如何求解电容电压
$du = \frac{1}{C} i \cdot dt$ 
$\int_{u(t_0)}^{u(t)} 1 \cdot du = \int_{t_0}^{t} \frac{1}{C} i(\tau) \, d\tau$
$u(t) = \frac{1}{C} \int_{t_0}^{t} i(\tau) \, d\tau + u(t_0)$

# 阻抗
## 原理
交流电路中电感和电容会对电流产生阻碍作用，但这种阻碍并非会消耗能量，只是不断的充电和放电。这就导致了电压和电流之间产生了**相位差**。
## 阻抗的分类、数学形式
电抗又分为感抗（$X_L$）和容抗（$X_C$）。 
$Z = R + jX$ 实部电阻与频率无关，虚部和频率相关。
- **感抗 ($X_L = \omega L$)：** 电感引起的阻碍作用。频率越高，感抗越大（高频阻流）。导致电压**超前**电流 $90^\circ$。
- **容抗 ($X_C = -\frac{1}{\omega C}$ 或表示为绝对值 $\frac{1}{\omega C}$ 带有 $-90^\circ$ 相位)：** 电容引起的阻碍作用。频率越高，容抗越小（高频通流）。导致电压**滞后**电流 $90^\circ$。
$X = X_L + X_C$ 
## 阻抗的物理意义
1. **幅值（大小）：** $|Z| = \sqrt{R^2 + X^2}$。它决定了在给定的电压幅值下，电路能流过多大的电流。这就像水管的粗细。公式为：$|I| = \frac{|U|}{|Z|}$。
2. **相位角（方向）：** $\theta = \arctan\left(\frac{X}{R}\right)$。它决定了电路中电压和电流之间的时间差（相位差）。

- **感性阻抗 ($X_L > |X_C|$ 即 $X > 0$)：** 电路整体表现得像一个电感，电压**超前**电流。
- **容性阻抗 ($X_L < |X_C|$ 即 $X < 0$)：** 电路整体表现得像一个电容，电压**滞后**电流。
- **阻性阻抗 ($X_L = |X_C|$ 即 $X = 0$)：** 感抗和容抗完全抵消，电路整体表现得像一个纯电阻，电压和电流**同相**。这种情况被称为**谐振（Resonance）**。

# 导纳
## 既然有了阻抗，为什么还要发明“导纳”？

为了**偷懒**，特别是在计算**并联电路**的时候。
- **串联电路中，用“阻抗”最方便：**
    因为串联电路电流相等，总电压等于各部分电压之和，所以总阻抗直接相加：
    $Z_{total} = Z_1 + Z_2 + Z_3$
- **并联电路中，用“导纳”最方便：**
    因为并联电路电压相等，总电流等于各支路电流之和（根据 KCL：$\dot{I} = \dot{I}_1 + \dot{I}_2$）。
    如果不引入导纳，你计算总阻抗的公式会非常恶心：
    $\frac{1}{Z_{total}} = \frac{1}{Z_1} + \frac{1}{Z_2}$ （这在复数运算里通分简直是噩梦）。
    **但如果用导纳，并联的总导纳直接相加即可：**
    $Y_{total} = Y_1 + Y_2 + Y_3$

| 特性     | 阻抗 (Z)             | 导纳 (Y)               |
| ------ | ------------------ | -------------------- |
| 物理意义   | 阻碍交流电的能力           | 允许交流电通过的能力           |
| 公式     | Z=I˙U˙​            | Y=U˙I˙​=Z1​          |
| 组成     | Z=R+jX (电阻 + 电抗)   | Y=G+jB **(电导 + 电纳)** |
| 单位     | 欧姆 (Ω)             | 西门子 (S)              |
| 最适用的场景 | 串联电路 (Z总​=Z1​+Z2​) | 并联电路 (Y总​=Y1​+Y2​)   |
超前关系和阻抗相反。

## 相量图
在交流电路里，根据基尔霍夫定律（KCL/KVL），总电压或总电流是各个支路的和。但复数相加（比如 $3\angle 30^\circ + 4\angle -60^\circ$）算起来很麻烦。 在相量图上，你只需要用“平行四边形法则”**或者**“首尾相连”的方法，把几根线段拼在一起，画出的对角线就是总电压或总电流！直观又不容易算错。

- **纯电阻 (R)：** 电压和电流“穿一条裤子”，它们的相量画出来是**重合、或者平行的**（夹角为 $0^\circ$）。
- **纯电感 (L)：** 电压永远在电流的逆时针方向 $90^\circ$ 处（**电压超前电流 $90^\circ$**）。
- **纯电容 (C)：** 电压永远在电流的顺时针方向 $90^\circ$ 处（**电压滞后电流 $90^\circ$**）。

画图的第一步是找共用的物理量，把它画在 $0^\circ$（水平向右）的位置作为参考。
- **串联电路：** 大家都流过同一个电流，所以**把总电流 $\dot{I}$ 设为参考相量**。
- **并联电路：** 大家都承受同一个电压，所以**把总电压 $\dot{U}$ 设为参考相量**。

## 串联谐振与并联谐振
### 串联谐振
$$\dot{U}_s = \dot{I} (R + j\omega L - j\frac{1}{\omega C})$$ **串联电路的欧姆定律**（总电压 = 总电流 $\times$ 总阻抗）电感的感抗会随着频率变高而变大，电容的容抗会随着频率变高而变小。总有那么一个特定的频率（谐振频率），能让感抗（$\omega L$）和容抗（$\frac{1}{\omega C}$）在数值上**绝对相等**。结论： **$\dot{U}_L + \dot{U}_C = 0$** 

### 并联谐振
当 $\omega C = \frac{1}{\omega L}$ 时，并联谐振发生。因为总阻抗变得极大，电源能够输送进这个并联电路的总电流 $\dot{I}$ 会瞬间降到**最小**。这是并联谐振最核心的特征！虽然电源提供的总电流很小，但在并联的电感和电容**内部支路**里，却极其巨大的电流！
