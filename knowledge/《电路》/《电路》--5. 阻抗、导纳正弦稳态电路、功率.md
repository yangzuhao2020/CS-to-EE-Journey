# 阻抗
## 原理
交流电路中电感和电容会对电流产生阻碍作用，但这种阻碍并非会消耗能量，只是不断的充电和放电。这就导致了电压和电流之间产生了**相位差**。
## 阻抗的分类、数学形式
电抗又分为感抗（$X_L$）和容抗（$X_C$）。
$Z = R + jX$ 实部电阻与频率无关，虚部和频率相关。
- **感抗 ($X_L = \omega L$)：** 电感引起的阻碍作用。频率越高，感抗越大（高频阻流）。导致电压**超前**电流 $90^\circ$。
- **容抗 ($X_C = -\frac{1}{\omega C}$ 或表示为绝对值 $\frac{1}{\omega C}$ 带有 $-90^\circ$ 相位)：** 电容引起的阻碍作用。频率越高，容抗越小（高频通流）。导致电压**滞后**电流 $90^\circ$。
$X = X_L + X_C$
## 阻抗的物理意义
1. **幅值（大小）：** $|Z| = \sqrt{R^2 + X^2}$。它决定了在给定的电压幅值下，电路能流过多大的电流。这就像水管的粗细。公式为：$|I| = \frac{|U|}{|Z|}$。
2. **相位角（阻抗角）：** $\theta = \arctan\left(\frac{X}{R}\right)$。它决定了电路中电压和电流之间的时间差（相位差）。

- **感性阻抗 ($X_L > |X_C|$ 即 $X > 0$)：** 电路整体表现得像一个电感，电压**超前**电流。
- **容性阻抗 ($X_L < |X_C|$ 即 $X < 0$)：** 电路整体表现得像一个电容，电压**滞后**电流。
- **阻性阻抗 ($X_L = |X_C|$ 即 $X = 0$)：** 感抗和容抗完全抵消，<mark style="background: #FF5582A6;">电路整体表现得像一个纯电阻</mark>，电压和电流**同相**。这种情况被称为**谐振（Resonance）**。

# 导纳
## 既然有了阻抗，为什么还要发明“导纳”？

为了**偷懒**，特别是在计算**并联电路**的时候。
- **串联电路中，用“阻抗”最方便：**
    因为串联电路电流相等，总电压等于各部分电压之和，所以总阻抗直接相加：
    $Z_{total} = Z_1 + Z_2 + Z_3$
- **并联电路中，用“导纳”最方便：**
    因为并联电路电压相等，总电流等于各支路电流之和（根据 KCL：$\dot{I} = \dot{I}_1 + \dot{I}_2$）。
    如果不引入导纳，你计算总阻抗的公式会非常恶心：
    $\frac{1}{Z_{total}} = \frac{1}{Z_1} + \frac{1}{Z_2}$ （这在复数运算里通分简直是噩梦）。
    **但如果用导纳，并联的总导纳直接相加即可：**
    $Y_{total} = Y_1 + Y_2 + Y_3$

| 特性     | 阻抗 (Z)             | 导纳 (Y)               |
| ------ | ------------------ | -------------------- |
| 物理意义   | 阻碍交流电的能力           | 允许交流电通过的能力           |
| 公式     | Z=I˙U˙​            | Y=U˙I˙​=Z1​          |
| 组成     | Z=R+jX (电阻 + 电抗)   | Y=G+jB **(电导 + 电纳)** |
| 单位     | 欧姆 (Ω)             | 西门子 (S)              |
| 最适用的场景 | 串联电路 (Z总​=Z1​+Z2​) | 并联电路 (Y总​=Y1​+Y2​)   |
超前关系和阻抗相反。

## 相量图
在交流电路里，根据基尔霍夫定律（KCL/KVL），总电压或总电流是各个支路的和。但复数相加（比如 $3\angle 30^\circ + 4\angle -60^\circ$）算起来很麻烦。 在相量图上，你只需要用“平行四边形法则”**或者**“首尾相连”的方法，把几根线段拼在一起，画出的对角线就是总电压或总电流！直观又不容易算错。

- **纯电阻 (R)：** 电压和电流“穿一条裤子”，它们的相量画出来是**重合、或者平行的**（夹角为 $0^\circ$）。
- **纯电感 (L)：** 电压永远在电流的逆时针方向 $90^\circ$ 处（**电压超前电流 $90^\circ$**）。
- **纯电容 (C)：** 电压永远在电流的顺时针方向 $90^\circ$ 处（**电压滞后电流 $90^\circ$**）。

画图的第一步是找共用的物理量，把它画在 $0^\circ$（水平向右）的位置作为参考。
- **串联电路：** 大家都流过同一个电流，所以**把总电流 $\dot{I}$ 设为参考相量**。
- **并联电路：** 大家都承受同一个电压，所以**把总电压 $\dot{U}$ 设为参考相量**。

## 串联谐振与并联谐振
### 谐振的原理
谐振就是电路在某一特定频率下，电感和电容的作用正好抵消，使电路呈现纯电阻特性，并出现电流最大或阻抗最大的特殊现象。 
### 串联谐振
$$\dot{U}_s = \dot{I} (R + j\omega L - j\frac{1}{\omega C})$$ **串联电路的欧姆定律**（总电压 = 总电流 $\times$ 总阻抗）电感的感抗会随着频率变高而变大，电容的容抗会随着频率变高而变小。总有那么一个特定的频率（谐振频率），能让感抗（$\omega L$）和容抗（$\frac{1}{\omega C}$）在数值上**绝对相等**。结论： **$\dot{U}_L + \dot{U}_C = 0$**

### 并联谐振
当 $\omega C = \frac{1}{\omega L}$ 时，并联谐振发生。因为总阻抗变得极大，电源能够输送进这个并联电路的总电流 $\dot{I}$ 会瞬间降到**最小**，互成 180了。这是并联谐振最核心的特征！虽然电源提供的总电流很小，但在并联的电感和电容**内部支路**里，却极其巨大的电流！

| **特性**        | **串联谐振 (Series Resonance)** | **并联谐振 (Parallel Resonance)** |
| ------------- | --------------------------- | ----------------------------- |
| **电路连接**      | R, L, C 串联                  | R, L, C 并联                    |
| **分析工具**      | 阻抗 ($Z = R + jX$)           | 导纳 ($Y = G + jB$)             |
| **触发条件**      | 感抗 = 容抗 ($X_L = X_C$)       | 感纳 = 容纳 ($B_L = B_C$)         |
| **总阻抗 ($Z$)** | 达到 **最小值** ($Z = R$)        | 达到 **最大值** ($Z = R$)          |
| **总电流 ($I$)** | 达到 **最大值**                  | 达到 **最小值**                    |
| **极端危险**      | **电压谐振** (元件两端产生高压)         | **电流谐振** (内部支路产生大电流)开路        |
| **实际应用**      | 收音机的选频电路（让特定频率通过）           | 信号阻波器（把特定频率挡在门外）              |
# 功率
## 瞬时功率（UI 选择有效值）
瞬时功率是电路在某一时刻吸收或发出的功率。设端口电压和电流分别为：
$u(t) = \sqrt{2}U \cos(\omega t + \theta_u)$
$i(t) = \sqrt{2}I \cos(\omega t + \theta_i)$
其中，$U$ 和 $I$ 是有效值，$\theta_u$ 和 $\theta_i$ 是初相位，$\varphi = \theta_u - \theta_i$ 是阻抗角（即电压与电流的相位差）。
$$p(t) = u(t)i(t) = UI\cos\varphi + UI\cos(2\omega t + \theta_u + \theta_i)$$
$$p = I^2R(1+\cos2\omega t) - I^2\left(\omega L - \frac{1}{\omega C}\right)\sin2\omega t$$
瞬时功率包含两部分：一个恒定分量 $UI\cos\varphi$ ,以及一个以两倍电源频率波动**周期分量/交流分量**。
## 有功功率
有功功率是瞬时功率在一个周期内的平均值，也称为**平均功率**。它代表电路实际消耗掉的能量（例如转化为热能、机械能等）。电容、电感的无功功率为 0
- **公式：** $P = UI\cos\varphi$
- **单位：** 瓦特 (W) 或 千瓦 (kW)
- **注意：** 只有电阻元件才会消耗有功功率。
## 无功功率 (Reactive Power, $Q$)
无功功率表示**电源与电路中的储能元件**（电感、电容）之间进行**能量交换的最大速率**。它不作有用功，但对于建立磁场和电场是必不可少的。 【本质上是能量的交换和振荡】
	比如：电动机要工作，首先必须**建立磁场**。当电流涌入时，线圈把电能变成磁场能存起来；当电流退去时，磁场坍塌，又把能量原封不动地还给电网。由于这种“先借后还”的特性，导致了**电压和电流的步伐不一致**（产生了相位差）。这种在电源和负载之间来回晃荡、没有真正被“用掉”的功率，就是无功功率。
- **公式：** $Q = UI\sin\varphi= UI \sin(\varphi_u - \varphi_i) = I^2 X_L = \frac{U_L^2}{X_L} = U_L \cdot I$
- **单位：** 乏 (var) 或 千乏 (kvar)
- _感性负载_（如电动机，$\varphi > 0$）吸收正的无功功率；_容性负载_（$\varphi < 0$）发出（或吸收负的）无功功率。 
## 视在功率 (Apparent Power, $S$)
视在功率是电压有效值与电流有效值的乘积。它通常用来表示电气设备（如变压器、发电机）的容量，即设备在规定电压和电流下能提供的最大功率。
- **公式：** $S = UI$
- **单位：** 伏安 (VA) 或 千伏安 (kVA)
- **关系：** 视在功率、有功功率和无功功率构成一个直角三角形（功率三角形），满足：$S = \sqrt{P^2 + Q^2}$
## 功率因数 (Power Factor, $\lambda$ 或 $\cos\varphi$)
功率因数是有功功率与视在功率的比值，反映了电源容量的利用率。
- **公式：** $\lambda = \frac{P}{S} = \cos\varphi$
- 功率因数越接近 **1**，说明设备消耗的有功功率占视在功率的比例越大，**电网的传输效率越高。**
## 复功率
为了在相量法中方便地进行功率计算，引入了复功率的概念。复功率是电压相量与电流共轭相量的乘积。
- **公式：** $\tilde{S} = \dot{U}\dot{I}^* = P + jQ$
- 复功率的模即为视在功率 $S$，实部为**有功功率** $P$，虚部为**无功功率** $Q$，辐角即为阻抗角 $\varphi$。
- 举例：电压相量：$\dot{U} = 6\angle 30^\circ$ 电流相量：$\dot{I} = 2\angle -30^\circ$
	- 先把电流取共轭：$\dot{I}^* = 2\angle 30^\circ$
	- 代入复功率公式：$$\dot{S} = \dot{U}\dot{I}^* = (6\angle 30^\circ) \cdot (2\angle 30^\circ) = 12\angle 60^\circ$$ **注意：角度相乘符合幂的加法。**
	- 用欧拉公式（或三角函数）把极坐标写成直角坐标：$$\dot{S} = 12 \cdot \cos 60^\circ + j12 \cdot \sin 60^\circ = 12 \cdot \frac{1}{2} + j12 \cdot \frac{\sqrt{3}}{2} = 6 + j6\sqrt{3}$$
- 其他形式：
	- 阻抗形式：$$\tilde{S} = P + jQ =I^2Z= I^2 R + j I^2 X = I^2(R + jX)$$
	- 导纳形式：$$\tilde{S} =\dot{U} (\dot{U} Y)^= U^2 (G - jB) = U^2G - jU^2B$$
