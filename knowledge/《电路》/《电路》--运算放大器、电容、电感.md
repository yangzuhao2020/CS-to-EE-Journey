## 电容的功率与能量
- **电流与电压关系：** 流过电容的电流 $i$ 与电压 $u$ 的变化率成正比，公式为 $i = C \frac{du}{dt}$。
- **吸收功率 ($p$)：** 功率等于电压乘以电流，即 $p = u \cdot i = u \cdot C \frac{du}{dt}$ （板书中在公式下方标注了“吸收”）。
- **储存能量 ($W$)：** 能量是功率在一段时间段内的积分。
    - **积分推导：** $W = \int_{t_1}^{t_2} p \, dt = \int_{t_1}^{t_2} uC \frac{du}{dt} \, dt = \int_{t_1}^{t_2} C \cdot u \, du = \frac{1}{2}Cu^2 \Big|_{t_1}^{t_2}$
    - **核心结论：** 电容在某一时刻储存的能量公式为 $W = \frac{1}{2}Cu^2$。
    - 在时间段 $t_1$ 到 $t_2$ 内，电容能量的变化量表示为 $W(t_2) - W(t_1)$。
## 元件的分类：有源元件 vs 无源元件、无损原件
- **无源元件：** 包括电阻 (R)、电感 (L)、电容 (C)。板书中明确点出“电容：无源”。同时属于无损原件。
- **有源元件：** 包括独立电源、受控源。
- **核心判断标准：** 看该元件**是否可以对外提供“净功率”**。如果能持续对外提供净功率，就是有源元件；否则就是无源元件。

## 电感(隔变通直)
**电感两端的电压：**$$V = -L\frac{di}{dt}=-\frac{d\Psi}{dt}$$
这个公式完美解释了电感的特性：电感两端的电压（$V$）与电流的**变化率**（$\frac{di}{dt}$）成正比。如果电流不变化（直流电），$\frac{di}{dt} = 0$，那么电感两端的电压为0，相当于一根普通的导线（短路）。如果电流瞬间断开（$\frac{di}{dt}$ 无限大），电感会产生极高的电压，这就是拔掉大功率电器插头时会看到火花的原因。
**磁场中储存的能量：**
$$E = \frac{1}{2} L I^2$$
能量（$E$）与电感量（$L$）和当前电流（$I$）的平方成正比。
**磁通量**：
$$\Psi = N \cdot \Phi$$
_(其中 $\Psi$ 是磁链，$N$ 是线圈匝数，$\Phi$ 是穿过单匝线圈的磁通量)_
电感量（$L$）其实就是“每通入1安培的电流，这个线圈能产生多少磁链”的比例常数。
公式如下：$L = \frac{\Psi}{I}$ 
**方向问题:**
$\varepsilon = -u$ 或 $u = -\varepsilon$ 在电路学里，我们通常采用“关联参考方向”。电感是一个吸收能量的元件，外部加给它的电压 $u$ 与它内部产生的抵抗电动势 $\varepsilon$ 作用是相反的。
**在直流电稳定后，电感的作用完全消失了，它就变成了一根普通的导线（短路）**。此时电路中的电流就单纯由我们最熟悉的欧姆定律决定。**如果是接交流电**，电流会一直被电感压制着，比单纯只有电阻时（$V/R$）要小得多。

## 电容的串并联
这在工程中是最有意义的对比。假设你有 $n$ 个一模一样的电容，每个电容的容量都是 $C$，最高耐压都是 $U$。
- **全部并联**：总电容变为 $nC$，但整个组合的最高耐压依然是 $U$。
    $$W_{并} = \frac{1}{2} (nC) U^2 = n \cdot \left(\frac{1}{2}CU^2\right)$$
- **全部串联**：总电容变为 $\frac{C}{n}$，但整个组合的最高耐压提升成了 $nU$。
    $$W_{串} = \frac{1}{2} \left(\frac{C}{n}\right) (nU)^2 = \frac{1}{2} \cdot \frac{C}{n} \cdot n^2U^2 = n \cdot \left(\frac{1}{2}CU^2\right)$$
> 🏆 **结论**：如果发挥出每个电容的极限（都充到它们各自的额定耐压），无论是串联还是并联，**最终的总储能是完全一样的**，都等于所有单体电容能量的总和。
- 想在**低电压**下存更多电：用**并联**（堆容量）。
- 想在**高电压**下存更多电：用**串联**（堆耐压）。

| 特性      | 并联 (Parallel)        | 串联 (Series)          |
| ------- | -------------------- | -------------------- |
| 电路连接    | 首首相连，尾尾相连            | 首尾顺次相连               |
| 容量变化    | 变大（各电容相加）            | 变小（比其中任意一个都小）        |
| 电容量公式   | C总​=C1​+C2​+…        | C总​1​=C1​1​+C2​1​+…  |
| 电压 (U)  | 各支路电压相等：U总​=U1​=U2​  | 各电容分压：U总​=U1​+U2​    |
| 电荷量 (Q) | 各支路电荷量相加：Q总​=Q1​+Q2​ | 各电容电荷量相等：Q总​=Q1​=Q2​ |
| 核心目的    | 增加电容量                | 提高耐压值 / 减小电容量        |
- **特斯拉储能站（高容量、持久）**：作为化学电池，它的**能量密度极高**。一个特斯拉 Megapack 储能单元可以储存接近 4 兆瓦时（$4\text{ MWh} = 4000\text{ 度电}$）的电能，能持续为数千户家庭供电数小时。
- **电容（超低容量、短命）**：即使是现在最先进的“超级电容”，其能量密度也远低于锂电池。如果把一个 Megapack 体积的电容充满电，它可能只能支撑电网几秒钟或几分钟就泄光了。
## 电感的串并联
把多个电感首尾相接，排成一条线连入电路。
### 串联规律
- **电流相等**：流过每个电感的电流都是一样的。
    $$I_{总} = I_1 = I_2 = I_3 = \dots$$
- **电压分压**：总电压等于各个电感两端的电压之和（电感越大，分得的交流电压越高）。
    $$U_{总} = U_1 + U_2 + U_3 + \dots$$
- **等效电感变大**：总电感等于各电感之和（相当于增加了线圈的匝数）。
    $$L_{总} = L_1 + L_2 + L_3 + \dots$$
### 并联规律
- **电压相等**：每个电感两端的交流电压都等于总交流电压。
    $$U_{总} = U_1 = U_2 = U_3 = \dots$$
- **电流分流**：总电流等于流过各个电感的电流之和。
    $$I_{总} = I_1 + I_2 + I_3 + \dots$$
- **等效电感变小**：总电感的倒数等于各电感倒数之和。
    $$\frac{1}{L_{总}} = \frac{1}{L_1} + \frac{1}{L_2} + \frac{1}{L_3} + \dots$$

| 特性     | 串联 (Series)   | 并联 (Parallel)       |
| ------ | ------------- | ------------------- |
| 电感量变化  | 变大            | 变小                  |
| 计算公式   | L总​=L1​+L2​+… | L总​1​=L1​1​+L2​1​+… |
| 电流 (I) | 各处电流相等        | 各支路电流相加             |
| 电压 (U) | 各电感分压相加       | 各支路电压相等             |
| 与电阻的规律 | 相同            | 相同                  |
| 与电容的规律 | 相反            | 相反                  |
