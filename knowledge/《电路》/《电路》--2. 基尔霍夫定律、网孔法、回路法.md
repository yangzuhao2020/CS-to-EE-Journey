## 基尔霍夫电流定律（KCL）
KCL（Kirchhoff's Current Law），也叫节点电流定律。它关注的是电路中的**节点（Node）**——也就是三条或更多条电线交汇的那个“十字路口”。
**定律内容：** 在任何时刻，流入一个节点的电流总和，必须等于流出该节点的电流总和。换种极其霸道的数学表述就是：**在一个节点上，所有电流的代数和为零（$\sum I = 0$）。**
**物理本质：电荷守恒。** 节点就像是十字路口，它本身是一个没有体积的点，既不能凭空“生”出电子，也不能“吃”掉电子。
## 基尔霍夫电压定律（KVL）
**定律内容：** 沿着电路中的任何一个<mark style="background: #FF5582A6;">闭合回路</mark>走一圈，所有元件上的电压升（电源提供的推力）和电压降（电阻等元件吃掉的推力）抵消之后，总和必定为零。数学表述为：**在一个闭合回路中，所有电压的代数和为零（$\sum U = 0$）。** 一般来说给恒定电源设为<mark style="background: #BBFABBA6;">负</mark>的，电阻为<mark style="background: #FFF3A3A6;">正</mark>，其他的元件从正到负为<mark style="background: #FFB8EBA6;">正</mark>。

KCL: 针对广义结点、结点、电流；KVL: 针对电压、回路、虚拟回路。

## 电阻和电导
**并联电路用电导：** 在并联电路中，总电阻的计算公式比较麻烦（$\frac{1}{R_{total}} = \frac{1}{R_1} + \frac{1}{R_2} + \dots$）。但如果改用**电导**，公式就变得非常简单：
$$G_{total} = G_1 + G_2 + G_3 + \dots$$
也就是说，**并联电路的总电导等于各支路电导的代数和**。这在分析复杂网络（如节点电压法）时，能极大地简化计算过程。

## 等效电路--三角型和Y型电路
为了在计算中互相替换这两种电路而不改变外部电路的电压和电流，我们需要使用等效变换公式。假设三个外部节点为 A、B、C：
- **Y型电阻**：设为 $R_a$（连节点A）、$R_b$（连节点B）、$R_c$（连节点C）。
- **$\Delta$型电阻**：设为 $R_{ab}$（接A、B之间）、$R_{bc}$（接B、C之间）、$R_{ca}$（接C、A之间）。
从 $\Delta$ 型转换为 Y 型 ($\Delta \rightarrow Y$)：
Y型网络中任意一个电阻的值，等于$\Delta$型网络中与该节点相连的两个电阻的乘积，除以$\Delta$型网络中三个电阻的总和。
$$R_a = \frac{R_{ab} \cdot R_{ca}}{R_{ab} + R_{bc} + R_{ca}}$$
$$R_b = \frac{R_{ab} \cdot R_{bc}}{R_{ab} + R_{bc} + R_{ca}}$$
$$R_c = \frac{R_{bc} \cdot R_{ca}}{R_{ab} + R_{bc} + R_{ca}}$$
从 Y 型转换为 $\Delta$ 型 ($Y \rightarrow \Delta$)：
$\Delta$型网络中任意一个电阻的值，等于Y型网络中所有两两电阻乘积之和，除以Y型网络中与该$\Delta$电阻相对的那个节点的电阻。
$$R_{ab} = \frac{R_a R_b + R_b R_c + R_c R_a}{R_c}$$
$$R_{bc} = \frac{R_a R_b + R_b R_c + R_c R_a}{R_a}$$
$$R_{ca} = \frac{R_a R_b + R_b R_c + R_c R_a}{R_b}$$
如果三个电阻阻值完全相同（平衡状态），那么转换关系非常简单：$R_{\Delta} = 3 \cdot R_Y$。

## 平衡电桥
```          
             A
             ●
            / \
        R1 /   \ R2
          /     \
       B ●---G---● D
          \     /
        R3 \   / R4
            \ /
             ●
             C
```
平衡时，B、D 两点电势相等，所以中间支路 G 中没有电流。
平衡条件：R1 × R4 = R2 × R3
等效电阻：$Req= [(R1 + R3)(R2 + R4)] / [(R1 + R3) + (R2 + R4)]$
不平衡时：
	方法一：节点电压法
	方法二：Y-Δ 等效变换

## KCL 和 KVL 的独立方程数
- KCL 任意选择(n-1) 节点。
- KVL 勾通所有节点但不形成回路的子树 (n-1)；b 是支路数；$$独立方程数量=b-(n-1)=b-n+1$$
## 网孔电流法
- 本质是KVL方程 **b-n+1**
一个回路的电压降总是等于一个回路的电压升。

## 回路电流法
电阻总是正，互阻(两个支路都流经这个电阻)取正还是取负，则由相关两个回路共有的支路上梁回路电流的方向是否相同而决定，同为正数，反为负数。
