## 网络函数
对于线性电路，输出响应和输入激励之间可以用一个比例系数联系起来。外部给电路的电压或电流是激励，想要观察的电压和电流是响应。

当电路中存在电容和电感时，情况发生变化，因为它们的阻抗与频率有关：
$$Z_R = R$$
$$Z_L = j\omega L$$
$$Z_C = \frac{1}{j\omega C}$$
所以在正弦稳态下，也可以写成：
$$\dot{Y} = K(j\omega)\dot{X}$$
其中：
- $\dot{X}$：输入激励的相量；
- $\dot{Y}$：输出响应的相量；
- $K(j\omega)$：网络函数，也就是频率响应；
- $\omega = 2\pi f$：角频率。
响应和激励的比较：$$K(j\omega) = \frac{\dot{U}_o}{\dot{U}_s} = \frac{j\omega L}{R + j\omega L}$$
## 驱动点函数
1. 输入阻抗
	给端口施加电压，观察流入电流：$$Z_i(j\omega) = \frac{\dot{U}_i}{\dot{I}_i}$$
	其中：
	- 激励可以看成输入电流 $\dot{I}_i$；
	- 响应是输入电压 ${\dot{U}_i}$；
	- 比值是输入阻抗；
2. 输入导纳
	用电压作为激励、用电流作为响应，就是导纳的形式。

## 谐振电路的品质因素 Q
目的：谐振电路储存能量的能力，与损耗能量的程度之比。
- 谐振频率 $f_0$：决定电路在“哪个频率”发生谐振。
- 品质因素 $Q$：决定谐振“有多强、多尖锐”。

谐振时，能量不断在电感和电容之间交换：
**电容的电场能量 ⇌ 电感的磁场能量**
如果电阻很小，能量损失很慢，振荡可以维持很久，Q 就高；如果电阻很大，能量很快变成热量，Q 就低。$Q = \frac{1}{\omega_0 C R} = \frac{1}{R} \sqrt{\frac{L}{C}}$
### Q 也叫电压放大倍数。
串联谐振时，总阻抗只有 $R$：$$I = \frac{U}{R}$$
电感电压为：$$U_L = I \omega_0 L$$
代入 $I = U/R$：$$U_L = U \frac{\omega_0 L}{R} = QU$$
### 串联和并联的区别。
串联谐振：
$$Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 C R} = \frac{f_0}{\Delta f}$$
并联谐振：
$$Q = \frac{R}{\omega_0 L} = \omega_0 C R$$
