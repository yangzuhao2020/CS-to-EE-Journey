## MPC
![[Pasted image 20260507222723.png]]
- Converter 转化器：执行具体动作。
- Optimizer: 
	- **指令 $s(k)/d(k)$：** 优化器根据目标，向预测器发送一堆瞎猜的指令（比如移相角占空比）。
	- cost function: 对比目标值 $x^*$ 和预测值 $x^p$
- Predictor:
	- 预测器吃进当前状态 $x(k)$ 和瞎猜的指令 $s(k)/d(k)$，经过公式计算，得出一个带字母 $p$ 的 $x^p$（Predicted 预测值）。
MPC Framework 中会执行多个循环来解决问题。

DT-MPC 的做法中的预测器 NSP：
	先用欧拉法做一个很快的粗预测，再用神经网络补偿欧拉法相对于高精度数字孪生模型的误差。**$下一步状态≈当前状态+步长×当前变化率$ 
	欧拉预测 + 神经网络残差修正 = 预测器 NSP

predictor 用来预测未来状态，optimizer 用代价函数去找最优控制量。
$$候选控制量 Ui​→NSP预测未来状态→计算代价 J(Ui​)→SSO比较并更新候选控制量$$
也就是说，**神经网络不是直接求最优值的**。它只是回答一个问题：
	如果我采用这个控制量​，下一步电压、电流、ZVS 情况会变成什么样？

## 稳态与暂态
电力电子控制常常有多个目标，例如：
- 输出电压跟踪；
- 降低电感峰峰值电流；
- 实现 ZVS 零电压开关；
- 提高效率。
但这些目标优先级并不是固定的。动态过程中，电压稳定最重要；稳态时，效率和 ZVS 更重要。

所以作者设计了一个 **priority-based cost function**。它用一个软门控函数控制次要目标的权重：
- 暂态时，优先压低电压误差；
- 稳态时，再激活 ZVS、电流应力等次要目标。

这样避免了次要目标干扰动态响应。

## 如何训练
- 电路网表定义 DAB 的拓扑和元件参数，然后设定控制目标：输出电压调节、峰值电感电流限制、ZVS 优化。之后用高保真数字孪生模型在大量工况下生成训练数据，再训练 NSP。
- NSP 的网络是 MLP，激活函数 ReLU，损失函数 MSE，优化器 Adam，学习率$1×10−3$，训练 100 个 epoch，batch size 为 256，网络尺寸为 {4,32,32,3}。
- **模型硬件化**。训练好的 PyTorch 模型经过 QAT 量化感知训练和结构化剪枝，权重被量化成 8-bit integer，然后通过 HLS4ML 转换成 FPGA 可综合的 RTL IP 核。输出精度设为 FP16，目标部署位置是 FPGA 的 PL 侧。
- **在线闭环控制**。每个控制周期内，PS 侧的 SSO 产生若干候选控制量 $(D_0, D_1, D_2)$，然后把这些候选点发给 PL 侧的 NSP。NSP 快速预测输出电压、电感电流、ZVS 相关状态等，再计算代价函数。SSO 根据代价函数继续做反射、扩张、收缩等搜索，最后选出最优相移比，传给 DSP 产生下一周期 PWM。论文强调，FPGA 上 NSP 每周期预测时间约 **1.12 μs**，而 DAB 开关周期是 **10 μs**，所以一个控制周期内大约可以支持 **9 次优化迭代**。
