# 问题
在带有30%风电渗透率的IEEE 39节点系统上，生成在总线16持续100ms的三相短路故障场景。

# 介绍
## Bus
电力系统中的“母线”或“电气节点”。IEEE 39节点系统一共有39个母线，因此编号为：
$$Bus 1,Bus 2,…,Bus 39$$
母线是连接设备的节点，输电线路是连接母线的通道。

| 名称         | 含义             |
| ---------- | -------------- |
| Gen2@Bus31 | 2号发电机连接在31号母线上 |
| Gen5@Bus34 | 5号发电机连接在34号母线上 |
## IEEE 39
- IEEE 39节点系统一共有：
	- **39个母线**：Bus 1～Bus 39；
	- **10台同步发电机**：G1～G10；
	- **46条线路/支路**。
- 所以39个母线中只有一部分连接发电机。Bus 16没有发电机，但连接了多条线路，因此可以在Bus 16施加三相短路，观察故障如何影响整个系统。
- IEEE 39节点模型把Bus 31设为平衡母线，并将2号发电机连接到Bus 31
## 潮流计算
在电力系统正常稳定运行时，电能从哪些发电机出发，经过哪些线路，最后流向哪些负荷。

## 相角参考
交流电压不仅有大小，还有相角：$$\dot{V} = V \angle \theta$$
但电力系统真正有意义的是不同母线之间的相角差，而不是绝对相角。因此需要选择一个母线作为参考，例如：$$\theta_{31} = 0^{\circ}$$
然后其他母线的角度都相对于Bus 31计算：$$\theta_{16} = -5^{\circ}, \quad \theta_{34} = 2^{\circ}$$
这类似于规定“海平面高度为0米”，然后其他位置都相对于海平面测量。
